# Event form create bounces to skyforms

Operators create an Event form by leaving superadmin for skyforms (`returnTo` the same Event page) and coming back to attach the Form URL / Short link. The skyforms editor is not embedded (ADR 0020: forms is a major panel). There is no Gecekodu template Form in production today; forms-backend drafts are the source, bound as a group-specific extra when one exists. Rejected: superadmin S2S creating a blank form without opening skyforms; a second forms product.
