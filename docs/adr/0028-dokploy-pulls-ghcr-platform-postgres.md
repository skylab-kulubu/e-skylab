# Dokploy pulls GHCR; one Postgres is the platform only

Dokploy on the production server never compiles club apps: no `docker build` on the prod host, no Dokploy Git/Nixpacks build. GitHub Actions publishes `linux/amd64` to GHCR; Dokploy only pulls a tag. Production pins **`:latest`** (club convention). Developer machines run tests; they may also build+push, but Actions is the release path.

The forms **product** stays **skyforms** (waffle SPA, Keycloak public client `skyforms`, roles `skyforms:*`). The HTTP API, GHCR image, compose/Dokploy DNS, and confidential client are **forms** — not `dotnet`. Keycloak does not rename `clientId` in place: new confidential `forms`, copy roles/maps/SA, switch env, disable `dotnet`. That IdP cut is under NPM, before Traefik. Container DNS `dotnet-api` → `forms` when Traefik replaces NPM. Two OAuth clients stay separate (public SPA vs confidential API). `.NET` the runtime is unrelated.

The single Postgres instance (ADR 0002) holds only platform databases (Keycloak, core, CMS, forms, SkyMail). Place, Guessr, Extremspor, and other club event apps stay on their own environments. This phase’s UIs on Dokploy: **superadmin**, **forms-frontend**, **skymail-frontend**. inscribed / ana site / arge stay later (still closed). Sequence: GHCR-publishable images → IdP client `forms` while NPM still owns DNS → Dokploy brings a **parallel** platform (one Postgres + Redis + Keycloak + Gotenberg + apps, dump/restore) on the same server beside NPM → preview → **one DNS cut** of `api.` / `admin.` / `forms.` / `e.` / skymail UI to Traefik → **delete NPM** and stop the old compose stack. Rejected: building on the VPS; stuffing Place/Guessr/Extremspor into the platform Postgres; moving inscribed/sites in this phase; leaving waffle on Vercel; keeping platform data plane on SSH compose; flipping hostnames one at a time; cutting DNS with no preview.
