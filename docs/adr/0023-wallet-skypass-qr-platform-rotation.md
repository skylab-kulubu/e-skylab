# Wallet SkyPass QR rotates on platform terms, not every open

In-app SkyPass QR still refreshes every open. Google Wallet has no every-open hook; it rotates on-device via `rotatingBarcode` TOTP. Period is 60 seconds (`periodMillis` 60000) — Google's generic and event-ticket prose is “typically every minute”; the how-to's 3-second example is not used for a club card (battery/noise). Optional `PassConstraints.screenshotEligibility=INELIGIBLE` (API allows it; older Wallet may still screenshot). Apple Wallet has no on-device rotate (DTS: rotating QR not supported). PassKit `webServiceURL` is the refresh path so the device can pull a new signed `.pkpass` (documented triggers: APNs when the pass actually changes, plus pull-to-refresh; updates are not guaranteed). Signed barcode `exp` is about 5 minutes as the window if an update did not arrive. Rejected: APNs-pushing a new `.pkpass` every 60 seconds (Apple: don't send unnecessary pushes; they coalesce; battery; iOS can disable automatic updates). Scanner (ADR 0022) accepts either a 60-second Google code or a 5-minute Apple code if unexpired and signed.
