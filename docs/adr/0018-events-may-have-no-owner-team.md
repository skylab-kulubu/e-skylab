# Events may have no Owner team

Club-wide seminars and sponsor collabs are Events without a team Group. When `ownerTeam` is set, it is a Keycloak group (AGC under ALGOLAB is still Owner team AGC, not ALGOLAB). Empty owner is Privileged-only. Do not revive a Java EventType table or invent a GENEL team to satisfy a NOT NULL column. HTTP paths and query names use `ownerTeam` / `team`; they must not say `eventType`. Certificate templates stay keyed by Event / ownerTeam string.
